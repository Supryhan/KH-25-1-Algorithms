## 2. Теоретичні відомості

### 2.1. Черга з пріоритетами

У звичайній черзі першим обробляється елемент, який був доданий першим. У **черзі з пріоритетами** першим вилучається елемент із найвищим пріоритетом.

Наприклад, є завдання з пріоритетами `4`, `8`, `3`. Першим потрібно обробити пріоритет `8`, навіть якщо його додали не першим.

Основні операції:

- `Insert(value)` — додати новий пріоритет;
- `PeekMax()` — переглянути найбільший пріоритет без вилучення;
- `RemoveMax()` — вилучити найбільший пріоритет;
- перевірка, чи структура порожня.

### 2.2. Бінарна max-купа

**Бінарна купа** — це майже повне бінарне дерево. У max-купі значення кожного батьківського вузла не менше за значення його дітей. Тому найбільший елемент завжди розташований у корені.

```text
        8
      /   \
     7     3
    / \
   4   1
```

Це дерево можна зберігати звичайним масивом:

```text
Індекс: [0, 1, 2, 3, 4]
Купа:   [8, 7, 3, 4, 1]
```

Для елемента з індексом `i`:

- індекс батька: `(i - 1) / 2`;
- індекс лівої дитини: `2 * i + 1`;
- індекс правої дитини: `2 * i + 2`.

### 2.3. Відновлення купи вгору

Новий елемент додається в кінець масиву. Якщо він більший за батька, елементи міняються місцями. Перевірка повторюється, доки властивість max-купи не буде відновлена.

Цю операцію часто називають `Swim`, `SiftUp` або «підняттям».

### 2.4. Відновлення купи вниз

Під час `RemoveMax` корінь вилучається, а на його місце переноситься останній елемент. Якщо він менший за одну з дітей, його міняють місцями з більшою дитиною.

Цю операцію називають `Sink`, `SiftDown` або «просіюванням вниз».

### 2.5. Heap Sort

Heap Sort виконує дві основні дії:

1. Перетворює масив на max-купу.
2. Послідовно переносить найбільший елемент із кореня в кінець масиву та відновлює купу для решти елементів.

Після кожного перенесення права частина масиву вже впорядкована.

**Інваріант:** перед кожною новою ітерацією ліва частина є max-купою, а права частина містить найбільші елементи на остаточних позиціях.

### 2.6. Часова і просторова складність

- `PeekMax` звертається до кореня й має складність `O(1)`.
- `Insert` може піднімати елемент від листка до кореня — `O(log n)`.
- `RemoveMax` може опускати елемент від кореня до листка — `O(log n)`.
- Heap Sort виконується за `Θ(n log n)` у найкращому, звичайному та найгіршому випадках.
- Наведений Heap Sort використовує `O(1)` додаткової пам’яті, бо змінює початковий масив.

| Складність | Приблизна кількість операцій для `n = 10` | Просте пояснення |
|---|---:|---|
| `O(1)` | 1 | Виконується одна проста дія |
| `O(log n)` | 3–4 | Перехід відбувається лише вздовж висоти дерева |
| `O(n)` | 10 | Переглядаються всі елементи |
| `O(n log n)` | 30–40 | Для багатьох елементів виконується рух уздовж дерева |
| `O(n²)` | 100 | Для кожного елемента переглядається багато інших |

### 2.7. Обов’язковий наочний приклад

Додамо пріоритети `[4, 8, 3, 7, 1]` до max-купи.

```text
Початок:          []
Insert(4):        [4]
Insert(8):        [4, 8] → [8, 4]
Insert(3):        [8, 4, 3]
Insert(7):        [8, 4, 3, 7] → [8, 7, 3, 4]
Insert(1):        [8, 7, 3, 4, 1]
```

Після всіх додавань корінь має найбільший пріоритет `8`.

**Перше вилучення:**

```text
RemoveMax() → 8
Останній елемент 1 переноситься в корінь:
[1, 7, 3, 4]

Просіювання вниз:
[7, 1, 3, 4] → [7, 4, 3, 1]
```

**Друге вилучення:**

```text
RemoveMax() → 7
[1, 4, 3] → [4, 1, 3]
```

Порядок вилучення починається з `8, 7`, тобто елементи обробляються від більшого пріоритету до меншого.

Для Heap Sort той самий початковий масив дає:

```text
До сортування:    [4, 8, 3, 7, 1]
Після сортування: [1, 3, 4, 7, 8]
```

## 6. Кодовий приклад

Приклад використовує масив як сховище max-купи. Змінна `size` показує, скільки позицій масиву реально зайнято. Методи `Swim` і `Sink` відновлюють властивість купи.

### Файл `Source/Practical5.cs`

```csharp
namespace TheoryOfAlgorithms.Source;

public static class Practical5
{
    public static void Insert(int[] heap, ref int size, int value)
    {
        heap[size] = value; // Новий елемент спочатку додається в кінець.
        Swim(heap, size);
        size++;
    }

    private static void Swim(int[] heap, int index)
    {
        while (index > 0)
        {
            int parent = (index - 1) / 2;
            if (heap[parent] >= heap[index]) break;
            Swap(heap, parent, index);
            index = parent;
        }
    }

    public static int RemoveMax(int[] heap, ref int size)
    {
        int max = heap[0]; // У корені max-купи міститься найбільше число.
        heap[0] = heap[size - 1];
        size--;
        Sink(heap, 0, size);
        return max;
    }

    private static void Sink(int[] heap, int index, int size)
    {
        while (2 * index + 1 < size)
        {
            int largerChild = 2 * index + 1;
            int rightChild = largerChild + 1;

            if (rightChild < size && heap[rightChild] > heap[largerChild])
                largerChild = rightChild;

            if (heap[index] >= heap[largerChild]) break;
            Swap(heap, index, largerChild);
            index = largerChild;
        }
    }

    public static void HeapSort(int[] values)
    {
        // Будуємо max-купу, починаючи з останнього батьківського вузла.
        for (int i = values.Length / 2 - 1; i >= 0; i--)
            Sink(values, i, values.Length);

        // Переносимо найбільший елемент у кінець невідсортованої частини.
        for (int end = values.Length - 1; end > 0; end--)
        {
            Swap(values, 0, end);
            Sink(values, 0, end);
        }
    }

    private static void Swap(int[] values, int first, int second)
    {
        int temp = values[first];
        values[first] = values[second];
        values[second] = temp;
    }

    public static void Run()
    {
        int[] priorities = { 4, 8, 3, 7, 1 }; // Дані свого варіанта.
        int[] heap = new int[priorities.Length];
        int size = 0;

        Console.WriteLine("Додавання до черги з пріоритетами:");
        foreach (int priority in priorities)
        {
            Insert(heap, ref size, priority);
            PrintHeap($"Insert({priority})", heap, size);
        }

        int first = RemoveMax(heap, ref size);
        Console.WriteLine($"RemoveMax: {first}");
        PrintHeap("Купа після вилучення", heap, size);

        int second = RemoveMax(heap, ref size);
        Console.WriteLine($"RemoveMax: {second}");
        PrintHeap("Купа після вилучення", heap, size);

        int[] sorted = (int[])priorities.Clone();
        HeapSort(sorted);
        Console.WriteLine($"Heap Sort: [{string.Join(", ", sorted)}]");
    }

    public static void PrintHeap(string name, int[] heap, int size)
    {
        Console.Write($"{name}: [");
        for (int i = 0; i < size; i++)
        {
            if (i > 0) Console.Write(", ");
            Console.Write(heap[i]);
        }
        Console.WriteLine("]");
    }
}
```

Вхідні дані містяться в масиві `priorities` у методі `Run`. Для свого варіанта потрібно змінити саме ці числа. `Insert` викликає відновлення вгору, `RemoveMax` — відновлення вниз, а `HeapSort` сортує окрему копію початкових даних.

## 7. Перевірка коректності

Тестовий випадок — це конкретний набір вхідних даних і відомий очікуваний результат. Перевірка успішна, якщо вилучається правильний максимум або масив правильно впорядковується.

| № | Вхідні дані | Що перевіряється | Очікуваний результат |
|---:|---|---|---|
| 1 | `[4, 8, 3, 7, 1]` | Звичайний випадок | перший максимум `8`, сортування `[1, 3, 4, 7, 8]` |
| 2 | `[5]` | Один елемент | `RemoveMax()` повертає `5` |
| 3 | `[]` | Порожній масив | Heap Sort залишає `[]` |
| 4 | `[3, 3, 1]` | Однакові пріоритети | сортування `[1, 3, 3]` |
| 5 | `[1, 2, 3, 4]` | Уже впорядкований масив | результат не змінюється |

### Файл `Tests/Practical5Tests.cs`

```csharp
using TheoryOfAlgorithms.Source;

namespace TheoryOfAlgorithms.Tests;

public static class Practical5Tests
{
    public static void RunTests()
    {
        int[] heap = new int[3];
        int size = 0;
        Practical5.Insert(heap, ref size, 4);
        Practical5.Insert(heap, ref size, 8);
        Practical5.Insert(heap, ref size, 3);
        CheckNumber("Вилучення максимуму",
            Practical5.RemoveMax(heap, ref size), 8);

        int[] values = { 4, 8, 3, 7, 1 };
        Practical5.HeapSort(values);
        CheckArray("Heap Sort", values, new[] { 1, 3, 4, 7, 8 });

        int[] repeated = { 3, 3, 1 };
        Practical5.HeapSort(repeated);
        CheckArray("Однакові значення", repeated, new[] { 1, 3, 3 });
    }

    private static void CheckNumber(string name, int actual, int expected)
    {
        Console.WriteLine(actual == expected
            ? $"Успішно: {name}" : $"Помилка: {name}");
    }

    private static void CheckArray(string name, int[] actual, int[] expected)
    {
        bool equal = actual.Length == expected.Length;
        for (int i = 0; i < actual.Length && equal; i++)
            if (actual[i] != expected[i]) equal = false;

        Console.WriteLine(equal ? $"Успішно: {name}" : $"Помилка: {name}");
    }
}
```

## 8. Теоретичний аналіз алгоритмів

| Операція | Основна дія | Часова складність | Додаткова пам’ять |
|---|---|---|---|
| `PeekMax` | звернення до `heap[0]` | `O(1)` | `O(1)` |
| `Insert` | порівняння з батьками | `O(log n)` | `O(1)` |
| `RemoveMax` | порівняння з дітьми | `O(log n)` | `O(1)` |
| Heap Sort | послідовне вилучення максимумів | `Θ(n log n)` | `O(1)` |

Зі збільшенням кількості елементів висота купи зростає повільно. Тому одна операція додавання або вилучення не переглядає весь масив, а проходить лише один шлях у дереві.
