# Практична робота 10. Цифрове сортування та структури даних для роботи з рядками

## Мета

Ознайомитися з особливостями обробки рядків, навчитися реалізовувати LSD-сортування коротких рядків однакової довжини, додавати й шукати слова у префіксному дереві, будувати впорядкований набір суфіксів одного слова та пояснювати залежність складності від кількості рядків, їхньої довжини й розміру алфавіту.

## 1. Передумови

Для виконання роботи достатньо знати рядки, символи, масиви, індекси, умови `if`, цикли `for`, методи та виведення через `Console.WriteLine`. Потрібно пам’ятати, що символи рядка в C# мають індекси від `0` до `Length - 1`.

У роботі використано простий клас `TrieNode`. Він зберігає масив посилань на наступні літери та логічне значення `IsWord`. Студенту не потрібно самостійно проєктувати цей клас — достатньо розібрати готовий приклад.

## 2. Теоретичні відомості

### 2.1. Особливості рядкових алгоритмів

Рядок складається із символів. Тому час роботи алгоритму залежить не лише від кількості рядків `N`, а й від їхньої довжини.

У цій роботі використовуються лише малі латинські літери `a..z`. Розмір алфавіту дорівнює `R = 26`.

Позначення:

- `N` — кількість рядків;
- `W` — довжина кожного рядка для LSD-сортування;
- `R` — кількість можливих символів алфавіту;
- `L` — довжина одного слова.

### 2.2. Цифрове сортування LSD

**LSD** означає *Least Significant Digit* — сортування починається з найменш значущої позиції, тобто з останнього символу.

Алгоритм обробляє позиції справа наліво. На кожній позиції виконується стабільне сортування за поточним символом. **Стабільність** означає, що рядки з однаковим символом зберігають свій попередній взаємний порядок.

У навчальній реалізації LSD працює лише за таких умов:

- усі рядки мають однакову довжину;
- усі символи — малі латинські літери `a..z`.

Часова складність становить `O(W · (N + R))`. Допоміжний масив рядків потребує `O(N)` пам’яті, масив лічильників — `O(R)`.

### 2.3. Префіксне дерево

**Префіксне дерево**, або **trie**, зберігає слова за їхніми символами. Спільні префікси використовують спільні вузли.

Для слів `cat`, `car`, `dog` дерево можна показати так:

```text
root
├─ c
│  └─ a
│     ├─ t *
│     └─ r *
└─ d
   └─ o
      └─ g *
```

Зірочка означає кінець повного слова.

Основні операції:

- `Insert(word)` — додати слово;
- `Search(word)` — перевірити наявність повного слова;
- `StartsWith(prefix)` — перевірити наявність хоча б одного слова з префіксом.

Якщо довжина слова дорівнює `L`, ці операції потребують `O(L)` часу. Кількість вузлів залежить від сумарної довжини слів і кількості спільних префіксів.

### 2.4. Суфікси рядка

**Суфікс** — частина рядка, яка починається з певної позиції й закінчується останнім символом.

Для слова `cat` суфіксами є:

```text
cat
at
t
```

Упорядкований набір суфіксів допомагає досліджувати повторювані фрагменти та виконувати пошук у тексті. У цій початковій роботі не будується складне суфіксне дерево. Програма лише створює всі суфікси короткого слова та впорядковує їх.

Побудова всіх суфіксів шляхом копіювання підрядків потребує приблизно `O(L²)` символів пам’яті. Їх упорядкування також залежить від кількості й довжини порівнюваних рядків.

### 2.5. Порівняння структур і алгоритмів

| Задача | Основна величина | Часова складність у прикладі |
|---|---|---|
| LSD-сортування | `N`, `W`, `R` | `O(W · (N + R))` |
| Додавання слова до trie | `L` | `O(L)` |
| Пошук слова у trie | `L` | `O(L)` |
| Побудова текстів усіх суфіксів | `L` | приблизно `O(L²)` пам’яті й копіювання |

Збільшення алфавіту збільшує масив лічильників LSD і масив дітей кожного вузла trie. Збільшення довжини рядків збільшує кількість проходів LSD та глибину дерева.

### 2.6. Обов’язковий наочний приклад LSD

Початкові слова:

```text
[cat, dog, ant, bee]
```

Усі слова мають довжину `3`.

**Сортування за останнім символом, позиція `2`:**

```text
cat → t
dog → g
ant → t
bee → e

Результат: [bee, dog, cat, ant]
```

**Сортування за середнім символом, позиція `1`:**

```text
bee → e
dog → o
cat → a
ant → n

Результат: [cat, bee, ant, dog]
```

**Сортування за першим символом, позиція `0`:**

```text
cat → c
bee → b
ant → a
dog → d

Кінцевий результат: [ant, bee, cat, dog]
```

### 2.7. Обов’язковий наочний приклад trie

Додаємо `cat`, `dog`, `ant`, `bee`.

```text
Insert("cat"): root → c → a → t*
Insert("dog"): root → d → o → g*
Insert("ant"): root → a → n → t*
Insert("bee"): root → b → e → e*
```

Перевірки:

```text
Search("cat") → true
StartsWith("do") → true
Search("cow") → false
```

### 2.8. Обов’язковий наочний приклад суфіксів

Суфікси слова `banana` до впорядкування:

```text
banana, anana, nana, ana, na, a
```

Після впорядкування:

```text
a, ana, anana, banana, na, nana
```

Перші три суфікси починаються з `a`, тому в упорядкованому наборі рядки зі спільним початком розташовуються поруч.

## 6. Кодовий приклад

Масив `count` зберігає кількість символів поточної позиції. Масив `output` тимчасово зберігає результат одного стабільного проходу. У trie індекс літери обчислюється як `word[i] - 'a'`: для `a` це `0`, для `b` — `1`.

### Файл `Source/Practical10.cs`

```csharp
namespace TheoryOfAlgorithms.Source;

public static class Practical10
{
    public class TrieNode
    {
        public TrieNode?[] Children = new TrieNode?[26];
        public bool IsWord;
    }

    public static void LsdSort(string[] words, bool showSteps)
    {
        int width = words[0].Length;
        string[] output = new string[words.Length];

        for (int position = width - 1; position >= 0; position--)
        {
            int[] count = new int[27];

            // Підраховуємо символи поточної позиції.
            foreach (string word in words)
            {
                int letter = word[position] - 'a';
                count[letter + 1]++;
            }

            // Перетворюємо кількості на початкові позиції символів.
            for (int letter = 0; letter < 26; letter++)
                count[letter + 1] += count[letter];

            // Стабільно розміщуємо слова у допоміжному масиві.
            foreach (string word in words)
            {
                int letter = word[position] - 'a';
                output[count[letter]++] = word;
            }

            for (int i = 0; i < words.Length; i++)
                words[i] = output[i];

            if (showSteps)
                Console.WriteLine($"Позиція {position}: " +
                                  $"[{string.Join(", ", words)}]");
        }
    }

    public static void Insert(TrieNode root, string word)
    {
        TrieNode current = root;
        foreach (char symbol in word)
        {
            int index = symbol - 'a';
            if (current.Children[index] == null)
                current.Children[index] = new TrieNode();
            current = current.Children[index]!;
        }
        current.IsWord = true;
    }

    public static bool Search(TrieNode root, string word)
    {
        TrieNode? node = FindNode(root, word);
        return node != null && node.IsWord;
    }

    public static bool StartsWith(TrieNode root, string prefix)
    {
        return FindNode(root, prefix) != null;
    }

    private static TrieNode? FindNode(TrieNode root, string text)
    {
        TrieNode? current = root;
        foreach (char symbol in text)
        {
            int index = symbol - 'a';
            current = current.Children[index];
            if (current == null) return null;
        }
        return current;
    }

    public static string[] BuildSortedSuffixes(string word)
    {
        string[] suffixes = new string[word.Length];
        for (int i = 0; i < word.Length; i++)
            suffixes[i] = word.Substring(i);

        Array.Sort(suffixes, StringComparer.Ordinal);
        return suffixes;
    }

    public static void Run()
    {
        string[] words = { "cat", "dog", "ant", "bee" }; // Дані варіанта.
        Console.WriteLine($"Початкові слова: [{string.Join(", ", words)}]");
        LsdSort(words, true);
        Console.WriteLine($"LSD-результат: [{string.Join(", ", words)}]");

        TrieNode root = new TrieNode();
        foreach (string word in words) Insert(root, word);

        Console.WriteLine($"Search(cat): {Search(root, "cat")}");
        Console.WriteLine($"StartsWith(do): {StartsWith(root, "do")}");
        Console.WriteLine($"Search(cow): {Search(root, "cow")}");

        string[] suffixes = BuildSortedSuffixes("banana");
        Console.WriteLine($"Суфікси banana: [{string.Join(", ", suffixes)}]");
    }
}
```

## 7. Перевірка коректності

Тестовий випадок містить конкретні рядки та відомий очікуваний результат. Перевірка успішна, якщо відсортований масив або логічний результат пошуку збігається з очікуваним.

| № | Вхідні дані | Що перевіряється | Очікуваний результат |
|---:|---|---|---|
| 1 | `cat, dog, ant, bee` | Звичайне LSD | `ant, bee, cat, dog` |
| 2 | `cat` | Одне слово | `cat` |
| 3 | `cat, cat` | Однакові рядки | `cat, cat` |
| 4 | trie зі словом `cat`, пошук `ca` | Префікс не є повним словом | `Search=false`, `StartsWith=true` |
| 5 | суфікси `cat` | Суфіксний аналіз | `at, cat, t` |

### Файл `Tests/Practical10Tests.cs`

```csharp
using TheoryOfAlgorithms.Source;

namespace TheoryOfAlgorithms.Tests;

public static class Practical10Tests
{
    public static void RunTests()
    {
        string[] words = { "cat", "dog", "ant", "bee" };
        Practical10.LsdSort(words, false);
        CheckArray("LSD-сортування", words,
            new[] { "ant", "bee", "cat", "dog" });

        Practical10.TrieNode root = new Practical10.TrieNode();
        Practical10.Insert(root, "cat");
        CheckBool("Повне слово", Practical10.Search(root, "cat"), true);
        CheckBool("Лише префікс", Practical10.Search(root, "ca"), false);
        CheckBool("Наявний префікс", Practical10.StartsWith(root, "ca"), true);

        string[] suffixes = Practical10.BuildSortedSuffixes("cat");
        CheckArray("Суфікси", suffixes, new[] { "at", "cat", "t" });
    }

    private static void CheckBool(string name, bool actual, bool expected)
    {
        Console.WriteLine(actual == expected
            ? $"Успішно: {name}" : $"Помилка: {name}");
    }

    private static void CheckArray(string name, string[] actual,
                                   string[] expected)
    {
        bool equal = actual.Length == expected.Length;
        for (int i = 0; i < actual.Length && equal; i++)
            if (actual[i] != expected[i]) equal = false;

        Console.WriteLine(equal ? $"Успішно: {name}" : $"Помилка: {name}");
    }
}
```

## 8. Теоретичний аналіз алгоритмів

| Алгоритм або операція | Основна операція | Часова складність | Додаткова пам’ять |
|---|---|---|---|
| LSD | розміщення рядка за символом | `O(W · (N + R))` | `O(N + R)` |
| `Insert` у trie | перехід за наступною літерою | `O(L)` | до `O(L)` нових вузлів |
| `Search` у trie | перехід за літерами слова | `O(L)` | `O(1)` |
| Побудова текстів суфіксів | копіювання підрядків | приблизно `O(L²)` | приблизно `O(L²)` |
