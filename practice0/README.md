# Практична робота 0. Пошук мінімального та максимального значень

## Мета

Сформувати початкові навички роботи зі змінними, масивами, циклами та умовними операторами; навчитися послідовно переглядати набір чисел, знаходити його мінімальний і максимальний елементи та перевіряти отриманий результат. Оцінити складність алгоритму.

## 1. Передумови

Для виконання роботи достатньо розуміти чотири базові поняття:

- **масив** зберігає набір чисел;
- **змінна** зберігає поточне значення;
- **цикл** послідовно переглядає числа;
- **умова** порівнює поточне число зі знайденим результатом.

Мета роботи — самостійно виконати цикл і порівняння. Тому не можна використовувати:

- `Math.Min` і `Math.Max`;
- `Enumerable.Min()` і `Enumerable.Max()`;
- `Array.Sort()`;

Чи будь-яке інше готове сортування.

## 2. Теоретичні відомості

Масив зберігає кілька значень одного типу. У цій роботі використовується масив цілих чисел `int[]`.

```csharp
int[] numbers = { 7, -3, 12, 4, -8, 5 };
```

Кожне число має індекс. Індекси в C# починаються з нуля.

```text
Індекс:  0   1   2  3   4  5
Число:  [7, -3, 12, 4, -8, 5]
```

Отже, число `7` має індекс `0`, а число `-8` — індекс `4`. Якщо рахувати звичайні позиції від одиниці, `-8` стоїть на п’ятій позиції.

**Мінімальне значення** — найменше число набору. **Максимальне значення** — найбільше число набору.
Наприклад:

```text
Масив:    [7, -3, 12, 4, -8, 5]
Мінімум:  -8
Максимум: 12
```

**Основна ідея алгоритму**: завести змінну для зберігання поточного мінімального та максимального значення та послідовно переглядати весь масив по одному елементу, якщо елемент більший за максимум чи менший за мінімум – необхідно оновити відповідну змінну.

Перед циклом змінні `minimum` і `maximum` потрібно правильно ініціалізувати. Не слід починати з нуля, -1 чи іншого фіксованого значення. Якщо всі числа додатні, нуль помилково залишиться мінімумом. Якщо всі числа від’ємні, нуль помилково залишиться максимумом.

Найпростіше записати обрати початковим перший елемент масиву:

```csharp
int minimum = numbers[0];
int maximum = numbers[0];
```

Цикл `foreach` по черзі записує кожний елемент масиву у змінну `number`:

```csharp
foreach (int number in numbers)
{
    // Тут перевіряється поточне число number.
}
```

Умова `number < minimum` перевіряє, чи знайдено новий мінімум. Умова `number > maximum` перевіряє, чи знайдено новий максимум:

```csharp
if (number < minimum) 
{
    // оновлення мінімуму
}
```

Тепер маючи всі складові частини необхідно зібрати алгоритм в один блок:

1. мінімум = перший елемент
2. в циклі перевіряємо всі елементи
3. якщо поточний елемент більше максимуму (або менший за мінімум) – оновлюємо максимум. Додаємо додаткові перевірки відповідно до завдання.
4. виведення результату.

### Приклад

Початковий масив:

```text
[7, -3, 12, 4, -8, 5]
```

Спочатку вважатимемо що перший елемент є мінімум і максимум:

```text
minimum = 7
maximum = 7
```

Далі проходитимемо по масиву й оновлюватимемо значення мінімуму та максимуму:

| Поточне число | Перевірка мінімуму | Новий `minimum` | Перевірка максимуму | Новий `maximum` |
|---:|---|---:|---|---:|
| `7` | `7 < 7` — ні | `7` | `7 > 7` — ні | `7` |
| `-3` | `-3 < 7` — так | `-3` | `-3 > 7` — ні | `7` |
| `12` | `12 < -3` — ні | `-3` | `12 > 7` — так | `12` |
| `4` | `4 < -3` — ні | `-3` | `4 > 12` — ні | `12` |
| `-8` | `-8 < -3` — так | `-8` | `-8 > 12` — ні | `12` |
| `5` | `5 < -8` — ні | `-8` | `5 > 12` — ні | `12` |

Кінцевий результат:

```text
Мінімальне значення: -8
Максимальне значення: 12
```

## 3. Постановка практичної задачі

Для заданого масиву чисел знайдіть вказане в завданні значення та виведіть результат на екран. Пошук виконайте самостійно за допомогою циклу та порівнянь, без готових функцій пошуку мінімуму, максимуму й сортування. Дані не потрібно вводити з клавіатури чи читаюти з файла - достатньо задати їх у програмному коді.

Оцініть складність `O(n)` реалізованого алгоритму.

## 3.1. Індивідуальні завдання

### Варіант 1. Мінімальний елемент

**Вхідні дані:** `[7, 3, 9, 2, 6]`.

**Потрібно:** знайти мінімальне число за допомогою циклу.

**Очікуваний результат:** `2`.

**Додаткова невелика зміна:** додайте число `1` і повторіть пошук.

**Підказка для тестів:** один елемент; усі числа однакові; мінімум на початку.

### Варіант 2. Максимальний елемент

**Вхідні дані:** `[-4, 8, 1, 12, 5]`.

**Потрібно:** знайти максимальне число за допомогою циклу.

**Очікуваний результат:** `12`.

**Додаткова невелика зміна:** замініть `12` на `6`.

**Підказка для тестів:** тільки від’ємні числа; один елемент; максимум на початку.

### Варіант 3. Мінімум і максимум

**Вхідні дані:** `[6, -2, 11, 4, -7]`.

**Потрібно:** за один прохід знайти мінімум і максимум.

**Очікуваний результат:** мінімум `-7`, максимум `11`.

**Додаткова невелика зміна:** додайте число `15`.

**Підказка для тестів:** один елемент; однакові числа; усі від’ємні.

### Варіант 4. Мінімум серед додатних чисел

**Вхідні дані:** `[-5, 8, 3, -2, 10]`.

**Потрібно:** пропускати числа, які не є додатними, і знайти найменше додатне.

**Очікуваний результат:** `3`.

**Додаткова невелика зміна:** додайте додатне число `1`.

**Підказка для тестів:** одне додатне число; кілька додатних; немає додатних чисел.

### Варіант 5. Максимум серед від’ємних чисел

**Вхідні дані:** `[-4, 7, -9, 2, -1]`.

**Потрібно:** пропускати невід’ємні числа і знайти найбільше від’ємне.

**Очікуваний результат:** `-1`.

**Додаткова невелика зміна:** додайте число `-2`.

**Підказка для тестів:** одне від’ємне число; усі від’ємні; немає від’ємних чисел.

### Варіант 6. Мінімальне парне число

**Вхідні дані:** `[7, 4, 9, 2, 6]`.

**Потрібно:** перевіряти `number % 2 == 0` і знайти мінімальне парне.

**Очікуваний результат:** `2`.

**Додаткова невелика зміна:** додайте парне число `0`.

**Підказка для тестів:** одне парне число; немає парних; від’ємні парні числа.

### Варіант 7. Максимальне парне число

**Вхідні дані:** `[3, 8, 5, 12, 7]`.

**Потрібно:** знайти найбільше число, для якого `number % 2 == 0`.

**Очікуваний результат:** `12`.

**Додаткова невелика зміна:** замініть `12` на `6`.

**Підказка для тестів:** одне парне; немає парних; усі парні.

### Варіант 8. Мінімальне непарне число

**Вхідні дані:** `[6, 9, 4, 3, 11]`.

**Потрібно:** знайти найменше число, яке не ділиться на `2` без остачі.

**Очікуваний результат:** `3`.

**Додаткова невелика зміна:** додайте непарне число `1`.

**Підказка для тестів:** одне непарне; немає непарних; від’ємні непарні.

### Варіант 9. Максимальне непарне число

**Вхідні дані:** `[2, 7, 4, 13, 9]`.

**Потрібно:** знайти найбільше непарне число.

**Очікуваний результат:** `13`.

**Додаткова невелика зміна:** додайте непарне число `15`.

**Підказка для тестів:** одне непарне; немає непарних; усі непарні.

### Варіант 10. Позиція мінімального елемента

**Вхідні дані:** `[8, 3, 6, 1, 5]`.

**Потрібно:** зберігати не лише мінімум, а й індекс, на якому його знайдено.

**Очікуваний результат:** мінімум `1`, індекс `3`, звичайна позиція `4`.

**Додаткова невелика зміна:** переставте число `1` на початок.

**Підказка для тестів:** мінімум на початку; мінімум наприкінці; один елемент.

### Варіант 11. Позиція максимального елемента

**Вхідні дані:** `[2, 7, 10, 4, 6]`.

**Потрібно:** зберігати максимальне число та його індекс.

**Очікуваний результат:** максимум `10`, індекс `2`, звичайна позиція `3`.

**Додаткова невелика зміна:** додайте число `12` наприкінці.

**Підказка для тестів:** максимум на початку; максимум наприкінці; один елемент.

### Варіант 12. Різниця між максимумом і мінімумом

**Вхідні дані:** `[5, -2, 9, 1, -6]`.

**Потрібно:** знайти мінімум і максимум, потім обчислити `maximum - minimum`.

**Очікуваний результат:** мінімум `-6`, максимум `9`, різниця `15`.

**Додаткова невелика зміна:** замініть `9` на `4`.

**Підказка для тестів:** один елемент — різниця `0`; однакові числа; усі від’ємні.

Для варіантів 4–9 використайте додаткову логічну змінну, наприклад `found`, щоб правильно обробити випадок, коли число потрібного типу відсутнє.
