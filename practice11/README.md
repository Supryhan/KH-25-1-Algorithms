## 2. Теоретичні відомості

### 2.1. Підрядок

**Підрядок** — це послідовна частина рядка. Наприклад, `abc` є підрядком рядка `xxabcxx` і починається з індексу `2`.

```text
Текст:   x x a b c x x
Індекс:  0 1 2 3 4 5 6
Шаблон:      a b c
Результат: 2
```

Якщо шаблон відсутній, метод повертає `-1`.

### 2.2. Наївний пошук

Наївний алгоритм послідовно прикладає шаблон до кожної можливої позиції тексту й порівнює символи зліва направо.

Якщо довжина тексту — `N`, а довжина шаблону — `M`, найгірша часова складність становить `O(N · M)`. Додаткова пам’ять — `O(1)`.

Алгоритм дуже простий і зручний для коротких текстів. Проте він може повторно порівнювати ті самі символи.

### 2.3. Алгоритм Кнута—Морріса—Пратта

Алгоритм **КМП** використовує інформацію про сам шаблон, щоб після невдалого порівняння не повертатися назад у тексті.

Допоміжний масив `prefix` зберігає довжину найбільшого власного префікса шаблону, який одночасно є суфіксом його поточної частини.

Для шаблону `ababc`:

```text
Символ:  a b a b c
Індекс:  0 1 2 3 4
prefix: [0,0,1,2,0]
```

Наприклад, для частини `abab` префікс `ab` одночасно є її суфіксом, тому значення дорівнює `2`.

Побудова масиву та пошук виконуються за `O(M + N)`. Для `prefix` потрібна пам’ять `O(M)`.

### 2.4. Скінченний автомат

**Скінченний автомат** має обмежену кількість станів. Кожний новий символ переводить автомат з одного стану до іншого.

У роботі автомат розпізнає коди такого вигляду:

```text
одна або більше малих латинських літер,
потім одна або більше цифр
```

Приклади:

```text
item123 → прийнято
box45   → прийнято
123item → відхилено
item    → відхилено
```

Стани автомата:

- `0` — початок, ще не прочитано літеру;
- `1` — читається група літер;
- `2` — читається група цифр;
- будь-який неправильний перехід завершує перевірку результатом `false`.

```text
0 --літера--> 1 --літера--> 1
               \
                --цифра--> 2 --цифра--> 2
```

Приймаючим є лише стан `2`.

### 2.5. Регулярний вираз

**Регулярний вираз** коротко описує текстовий шаблон. Еквівалентний шаблон для коду:

```text
^[a-z]+[0-9]+$
```

- `^` — початок рядка;
- `[a-z]+` — одна або більше малих латинських літер;
- `[0-9]+` — одна або більше цифр;
- `$` — кінець рядка.

Регулярні вирази зручні для перевірки форматів і виділення фрагментів. Складність залежить від конкретного виразу та реалізації механізму регулярних виразів. Для простого послідовного шаблону без складних повторень обробка зазвичай близька до лінійної відносно довжини тексту.

### 2.6. Порівняння підходів

| Підхід | Призначення | Часова складність у роботі | Додаткова пам’ять |
|---|---|---|---|
| Наївний пошук | знайти підрядок | найгірше `O(N · M)` | `O(1)` |
| КМП | знайти підрядок без повернення в тексті | `O(N + M)` | `O(M)` |
| Простий автомат | перевірити формат коду | `O(N)` | `O(1)` |
| Простий регулярний вираз | перевірити або виділити шаблон | залежить від шаблону | залежить від реалізації |

### 2.7. Обов’язковий наочний приклад пошуку

Текст: `abababc`, шаблон: `ababc`.

**Наївний пошук:**

```text
Позиція 0:
abab a
ababc
Перші 4 символи збіглися, a != c. Порівнянь: 5.

Позиція 1:
b != a. Порівнянь: 1.

Позиція 2:
ababc == ababc. Порівнянь: 5.

Результат: індекс 2
Загалом: 11 порівнянь
```

**КМП:**

Після невдачі на п’ятому символі алгоритм знає, що суфікс `ab` уже збігається з префіксом шаблону, тому не починає перевірку повністю спочатку.

```text
prefix = [0, 0, 1, 2, 0]
Результат: індекс 2
Порівнянь під час пошуку: 8
```

### 2.8. Обов’язковий наочний приклад автомата

Перевіримо `item123`:

```text
i: 0 → 1
t: 1 → 1
e: 1 → 1
m: 1 → 1
1: 1 → 2
2: 2 → 2
3: 2 → 2

Кінцевий стан: 2
Результат: true
```

Для `123item` перший символ `1` не має допустимого переходу зі стану `0`, тому результат — `false`.

## 6. Кодовий приклад

Обидва методи пошуку повертають індекс першого входження або `-1`. Параметр `comparisons` передається з `out` і повертає кількість порівнянь символів. Для регулярних виразів використовується стандартний простір імен `System.Text.RegularExpressions`.

### Файл `Source/Practical11.cs`

```csharp
using System.Text.RegularExpressions;

namespace TheoryOfAlgorithms.Source;

public static class Practical11
{
    public static int NaiveSearch(string text, string pattern,
                                  out int comparisons)
    {
        comparisons = 0;
        if (pattern.Length == 0) return 0;

        for (int start = 0; start <= text.Length - pattern.Length; start++)
        {
            int j = 0;
            while (j < pattern.Length)
            {
                comparisons++;
                if (text[start + j] != pattern[j]) break;
                j++;
            }
            if (j == pattern.Length) return start;
        }
        return -1;
    }

    public static int[] BuildPrefix(string pattern)
    {
        int[] prefix = new int[pattern.Length];
        int length = 0;

        for (int i = 1; i < pattern.Length;)
        {
            if (pattern[i] == pattern[length])
            {
                prefix[i] = length + 1;
                length++;
                i++;
            }
            else if (length > 0)
                length = prefix[length - 1];
            else
            {
                prefix[i] = 0;
                i++;
            }
        }
        return prefix;
    }

    public static int KmpSearch(string text, string pattern,
                                out int comparisons)
    {
        comparisons = 0;
        if (pattern.Length == 0) return 0;

        int[] prefix = BuildPrefix(pattern);
        int i = 0; // Індекс тексту.
        int j = 0; // Індекс шаблону.

        while (i < text.Length)
        {
            comparisons++;
            if (text[i] == pattern[j])
            {
                i++;
                j++;
                if (j == pattern.Length) return i - j;
            }
            else if (j > 0)
                j = prefix[j - 1];
            else
                i++;
        }
        return -1;
    }

    public static bool IsCodeByAutomaton(string text)
    {
        int state = 0;

        foreach (char symbol in text)
        {
            bool isLetter = symbol >= 'a' && symbol <= 'z';
            bool isDigit = symbol >= '0' && symbol <= '9';

            if (state == 0 && isLetter) state = 1;
            else if (state == 1 && isLetter) state = 1;
            else if (state == 1 && isDigit) state = 2;
            else if (state == 2 && isDigit) state = 2;
            else return false;
        }
        return state == 2;
    }

    public static bool IsCodeByRegex(string text)
    {
        return Regex.IsMatch(text, "^[a-z]+[0-9]+$");
    }

    public static void Run()
    {
        string text = "abababc"; // Дані індивідуального варіанта.
        string pattern = "ababc";

        int naiveIndex = NaiveSearch(text, pattern, out int naiveCount);
        int kmpIndex = KmpSearch(text, pattern, out int kmpCount);
        int[] prefix = BuildPrefix(pattern);

        Console.WriteLine($"Наївний пошук: індекс {naiveIndex}, " +
                          $"порівнянь {naiveCount}");
        Console.WriteLine($"КМП: індекс {kmpIndex}, порівнянь {kmpCount}");
        Console.WriteLine($"Prefix: [{string.Join(", ", prefix)}]");

        Console.WriteLine($"Автомат item123: {IsCodeByAutomaton("item123")}");
        Console.WriteLine($"Regex item123: {IsCodeByRegex("item123")}");
        Console.WriteLine($"Автомат 123item: {IsCodeByAutomaton("123item")}");

        string data = "item123 box45 bad_code book7";
        Console.Write("Знайдені коди: ");
        foreach (Match match in Regex.Matches(data, "[a-z]+[0-9]+"))
            Console.Write($"{match.Value} ");
        Console.WriteLine();
    }
}
```

## 7. Перевірка коректності

Тестовий випадок містить конкретний текст, шаблон або код і відомий результат. Перевірка успішна, якщо метод повертає очікуваний індекс або логічне значення.

| № | Вхідні дані | Що перевіряється | Очікуваний результат |
|---:|---|---|---|
| 1 | `abababc`, `ababc` | Звичайний пошук | індекс `2` |
| 2 | `abc`, `x` | Відсутній шаблон | `-1` |
| 3 | `abc`, порожній шаблон | Граничний випадок | `0` |
| 4 | `item123` | Правильний код | `true` |
| 5 | `item`, `123item` | Неправильні коди | `false` |

### Файл `Tests/Practical11Tests.cs`

```csharp
using TheoryOfAlgorithms.Source;

namespace TheoryOfAlgorithms.Tests;

public static class Practical11Tests
{
    public static void RunTests()
    {
        CheckNumber("Наївний пошук",
            Practical11.NaiveSearch("abababc", "ababc", out _), 2);
        CheckNumber("КМП",
            Practical11.KmpSearch("abababc", "ababc", out _), 2);
        CheckNumber("Шаблон відсутній",
            Practical11.KmpSearch("abc", "x", out _), -1);

        CheckBool("Правильний код",
            Practical11.IsCodeByAutomaton("item123"), true);
        CheckBool("Код без цифр",
            Practical11.IsCodeByRegex("item"), false);
    }

    private static void CheckNumber(string name, int actual, int expected)
    {
        Console.WriteLine(actual == expected
            ? $"Успішно: {name}" : $"Помилка: {name}");
    }

    private static void CheckBool(string name, bool actual, bool expected)
    {
        Console.WriteLine(actual == expected
            ? $"Успішно: {name}" : $"Помилка: {name}");
    }
}
```

**Підказка для тестів:** шаблон із пробілом; кінець тексту; код без цифр.
