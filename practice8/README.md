## 2. Теоретичні відомості

### 2.1. Зважений граф

У **зваженому графі** кожне ребро має числову вагу. Вага може позначати відстань, вартість, час або інший показник.

```text
0 ——2—— 1
 \      /
  6    3
   \  /
    3
```

У роботі використано неорієнтований граф: значення `weight[0, 1]` дорівнює `weight[1, 0]`. Нуль поза головною діагоналлю означає, що прямого ребра немає.

### 2.2. Остовне дерево

**Остовне дерево** зв’язного неорієнтованого графа:

- містить усі вершини;
- залишається зв’язним;
- не містить циклів;
- для `V` вершин має рівно `V - 1` ребро.

**Мінімальне остовне дерево** — це остовне дерево з найменшою сумою ваг усіх його ребер.

### 2.3. Алгоритм Прима

Алгоритм Прима починає з однієї вершини й поступово додає найдешевше ребро, яке з’єднує вже побудовану частину дерева з новою вершиною.

У коді використовуються масиви:

- `inTree[v]` — чи додано вершину `v` до дерева;
- `minEdge[v]` — найменша відома вага ребра до вершини `v`;
- `parent[v]` — з якої вершини найкраще приєднати `v`.

Алгоритм Прима застосовується до зв’язного неорієнтованого зваженого графа. Від’ємні ваги самі по собі не порушують його коректність, але в цій роботі використовуються лише додатні ваги.

### 2.4. Найкоротший шлях

Довжина шляху — це сума ваг його ребер. Найкоротший шлях між двома вершинами має найменшу сумарну вагу.

Важливо: мінімальне остовне дерево і дерево найкоротших шляхів — не одне й те саме. Остов мінімізує загальну вагу набору ребер для з’єднання всіх вершин. Алгоритм найкоротших шляхів мінімізує відстань від однієї заданої вершини до кожної іншої.

### 2.5. Алгоритм Дейкстри

Алгоритм Дейкстри зберігає найменші відомі відстані від початкової вершини:

- `distance[v]` — поточна найкраща відстань до `v`;
- `visited[v]` — чи остаточно оброблено вершину;
- `parent[v]` — попередня вершина найкоротшого шляху.

На кожному кроці вибирається необроблена вершина з найменшою відстанню. Потім програма перевіряє, чи можна покращити відстані до її сусідів.

Алгоритм Дейкстри коректно працює лише тоді, коли всі ваги ребер невід’ємні. Для графів із від’ємними вагами потрібен інший алгоритм, наприклад Беллмана — Форда.

### 2.6. Часова і просторова складність

У навчальній реалізації вершина з найменшим значенням шукається простим циклом. Тому обидва алгоритми мають часову складність `O(V²)`. Матриця ваг потребує `O(V²)` пам’яті, а допоміжні масиви — `O(V)`.

| Складність | Приклад для `V = 5` | Просте пояснення |
|---|---:|---|
| `O(1)` | 1 дія | розмір графа майже не впливає |
| `O(V)` | приблизно 5 дій | один перегляд вершин |
| `O(V²)` | приблизно 25 дій | для кожної вершини переглядаються всі вершини |

Варіант із чергою з пріоритетами може бути швидшим для розріджених графів, але в цій початковій роботі використовується наочна реалізація з матрицею.

### 2.7. Обов’язковий наочний приклад

Нехай граф має ребра:

```text
(0,1,2), (0,3,6), (1,2,3), (1,3,8),
(1,4,5), (2,4,7), (3,4,9)
```

Третє число кожної трійки — вага.

**Алгоритм Прима від вершини `0`:**

```text
Початок: дерево містить 0

Крок 1: додаємо 0—1, вага 2
Крок 2: додаємо 1—2, вага 3
Крок 3: додаємо 1—4, вага 5
Крок 4: додаємо 0—3, вага 6

Загальна вага: 2 + 3 + 5 + 6 = 16
```

Дерево містить усі п’ять вершин і чотири ребра.

**Алгоритм Дейкстри від вершини `0`:**

```text
Початкові відстані: [0, ∞, ∞, ∞, ∞]

Після вершини 0: [0, 2, ∞, 6, ∞]
Після вершини 1: [0, 2, 5, 6, 7]
Після вершини 2: [0, 2, 5, 6, 7]
Після вершини 3: [0, 2, 5, 6, 7]
Після вершини 4: [0, 2, 5, 6, 7]
```

Найкоротший шлях від `0` до `4`:

```text
0 → 1 → 4
Довжина: 2 + 5 = 7
```

## 6. Кодовий приклад

Значення `0` у матриці означає відсутність прямого ребра. Значення `int.MaxValue` використовується як умовна нескінченність — відстань, яку ще не знайдено.

### Файл `Source/Practical8.cs`

```csharp
namespace TheoryOfAlgorithms.Source;

public static class Practical8
{
    public static int Prim(int[,] weights, bool showEdges)
    {
        int n = weights.GetLength(0);
        bool[] inTree = new bool[n];
        int[] minEdge = new int[n];
        int[] parent = new int[n];

        for (int i = 0; i < n; i++)
        {
            minEdge[i] = int.MaxValue;
            parent[i] = -1;
        }
        minEdge[0] = 0; // Починаємо будувати дерево з вершини 0.

        for (int step = 0; step < n; step++)
        {
            int vertex = FindMinVertex(minEdge, inTree);
            inTree[vertex] = true;

            for (int next = 0; next < n; next++)
            {
                int weight = weights[vertex, next];
                if (weight > 0 && !inTree[next] && weight < minEdge[next])
                {
                    minEdge[next] = weight;
                    parent[next] = vertex;
                }
            }
        }

        int totalWeight = 0;
        for (int vertex = 1; vertex < n; vertex++)
        {
            totalWeight += weights[vertex, parent[vertex]];
            if (showEdges)
                Console.WriteLine($"{parent[vertex]} — {vertex}: " +
                                  $"{weights[vertex, parent[vertex]]}");
        }
        return totalWeight;
    }

    public static int[] Dijkstra(int[,] weights, int start, int[] parent)
    {
        int n = weights.GetLength(0);
        int[] distance = new int[n];
        bool[] visited = new bool[n];

        for (int i = 0; i < n; i++)
        {
            distance[i] = int.MaxValue;
            parent[i] = -1;
        }
        distance[start] = 0;

        for (int step = 0; step < n; step++)
        {
            int vertex = FindMinVertex(distance, visited);
            visited[vertex] = true;

            for (int next = 0; next < n; next++)
            {
                int weight = weights[vertex, next];
                if (weight > 0 && !visited[next] &&
                    distance[vertex] != int.MaxValue &&
                    distance[vertex] + weight < distance[next])
                {
                    distance[next] = distance[vertex] + weight;
                    parent[next] = vertex;
                }
            }
        }
        return distance;
    }

    private static int FindMinVertex(int[] values, bool[] used)
    {
        int minVertex = -1;
        for (int vertex = 0; vertex < values.Length; vertex++)
            if (!used[vertex] &&
                (minVertex == -1 || values[vertex] < values[minVertex]))
                minVertex = vertex;
        return minVertex;
    }

    public static void PrintPath(int[] parent, int start, int target)
    {
        int[] reversePath = new int[parent.Length];
        int length = 0;
        int current = target;

        while (current != -1)
        {
            reversePath[length++] = current;
            if (current == start) break;
            current = parent[current];
        }

        for (int i = length - 1; i >= 0; i--)
        {
            Console.Write(reversePath[i]);
            if (i > 0) Console.Write(" → ");
        }
        Console.WriteLine();
    }

    public static void Run()
    {
        int[,] weights =
        {
            { 0, 2, 0, 6, 0 },
            { 2, 0, 3, 8, 5 },
            { 0, 3, 0, 0, 7 },
            { 6, 8, 0, 0, 9 },
            { 0, 5, 7, 9, 0 }
        }; // Матриця ваг індивідуального варіанта.

        Console.WriteLine("Ребра мінімального остова:");
        int total = Prim(weights, true);
        Console.WriteLine($"Загальна вага: {total}");

        int[] parent = new int[weights.GetLength(0)];
        int[] distance = Dijkstra(weights, 0, parent);
        Console.WriteLine($"Відстані від 0: [{string.Join(", ", distance)}]");
        Console.Write("Шлях 0 → 4: ");
        PrintPath(parent, 0, 4);
    }
}
```

### Файл `Program.cs`


## 7. Перевірка коректності

Тестовий випадок містить конкретну матрицю ваг і відомий результат. Перевірка успішна, якщо вага остова або масив найкоротших відстаней збігається з очікуваним.

| № | Вхідні дані | Що перевіряється | Очікуваний результат |
|---:|---|---|---|
| 1 | граф прикладу | Обидва алгоритми | вага `16`, відстані `[0,2,5,6,7]` |
| 2 | дві вершини, ребро ваги `4` | Найменший зв’язний граф | вага `4`, відстані `[0,4]` |
| 3 | три вершини: `0—1=2`, `1—2=3` | Простий ланцюжок | вага `5`, відстань до `2` дорівнює `5` |
| 4 | трикутник із вагами `1`, `2`, `5` | Вибір дешевших ребер | вага остова `3` |
| 5 | одна вершина | Граничний випадок | вага `0`, відстань `[0]` |

### Файл `Tests/Practical8Tests.cs`

```csharp
using TheoryOfAlgorithms.Source;

namespace TheoryOfAlgorithms.Tests;

public static class Practical8Tests
{
    public static void RunTests()
    {
        int[,] twoVertices = { { 0, 4 }, { 4, 0 } };
        Check("Остов із одного ребра",
            Practical8.Prim(twoVertices, false), 4);

        int[] parent = new int[2];
        int[] distance = Practical8.Dijkstra(twoVertices, 0, parent);
        Check("Відстань до сусідньої вершини", distance[1], 4);

        int[,] triangle =
        {
            { 0, 1, 5 },
            { 1, 0, 2 },
            { 5, 2, 0 }
        };
        Check("Остов трикутника", Practical8.Prim(triangle, false), 3);

    {
        Console.WriteLine(actual == expected
            ? $"Успішно: {name}" : $"Помилка: {name}");
    }
}
```

## 8. Теоретичний аналіз алгоритмів

| Алгоритм | Основна операція | Часова складність | Додаткова пам’ять без матриці |
|---|---|---|---|
| Прима | вибір найменшого ребра до нової вершини | `O(V²)` | `O(V)` |
| Дейкстри | вибір найменшої відстані та її оновлення | `O(V²)` | `O(V)` |

Матриця ваг займає `O(V²)` пам’яті. При збільшенні кількості вершин удвічі кількість позицій матриці збільшується приблизно в чотири рази.
