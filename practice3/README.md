## 2. Теоретичні відомості

### 2.1. Що таке сортування

**Сортування** — це впорядкування елементів за певним правилом. У роботі числа розташовуються за зростанням.

```text
До сортування:    [7, 3, 5, 1]
Після сортування: [1, 3, 5, 7]
```

### 2.2. Сортування вибором

Алгоритм ділить масив на впорядковану ліву частину та невпорядковану праву. На кожному кроці він знаходить найменший елемент у правій частині й ставить його на наступну позицію зліва.

Основна операція — порівняння двох елементів. Для масиву з `n` елементів алгоритм виконує приблизно `n² / 2` порівнянь, тому часова складність становить `Θ(n²)`. Додаткова пам’ять — `O(1)`.

**Інваріант:** перед кожним новим проходом усі елементи ліворуч від позиції `i` вже стоять на правильних місцях і не перевищують елементів у правій частині.

### 2.3. Сортування вставками

Алгоритм бере наступний елемент і вставляє його у правильне місце серед уже впорядкованих елементів ліворуч. Це схоже на впорядкування карт у руці.

Для вже впорядкованого масиву потрібно приблизно `n` порівнянь — `Θ(n)`. Для масиву у зворотному порядку потрібно приблизно `n² / 2` порівнянь і переміщень — `Θ(n²)`. Додаткова пам’ять — `O(1)`.

**Інваріант:** перед початком кожної ітерації частина масиву від індексу `0` до `i - 1` уже впорядкована.

### 2.4. Сортування Шелла

Сортування Шелла спочатку порівнює елементи, що розташовані на певній відстані `gap`, а потім поступово зменшує цю відстань. У прикладі використано просту послідовність кроків `n / 2, n / 4, ..., 1`.

Коли `gap = 1`, виконується звичайне сортування вставками, але масив до цього моменту вже частково впорядкований. Для цієї простої послідовності кроків верхня оцінка може становити `O(n²)`, хоча на багатьох невеликих масивах алгоритм виконує менше операцій, ніж звичайні вставки. Додаткова пам’ять — `O(1)`.

**Інваріант:** після завершення проходу з певним `gap` елементи кожної групи, розташовані через `gap` позицій, упорядковані між собою.

### 2.5. Позначення складності

- `O(...)` показує верхню оцінку кількості операцій;
- `Ω(...)` показує нижню оцінку;
- `Θ(...)` означає однакову швидкість зростання зверху і знизу.

| Складність | Приблизна кількість операцій для `n = 10` | Просте пояснення |
|---|---:|---|
| `O(1)` | 1 | Розмір масиву майже не впливає на кількість дій |
| `O(log n)` | 3–4 | На кожному кроці обсяг роботи суттєво зменшується |
| `O(n)` | 10 | Потрібно один раз переглянути всі елементи |
| `O(n²)` | 100 | Для кожного елемента переглядається багато інших елементів |

Якщо розмір масиву збільшити з 10 до 20, лінійний алгоритм виконає приблизно вдвічі більше операцій, а квадратичний — приблизно в чотири рази більше.

### 2.6. Обов’язковий наочний приклад

Розглянемо сортування вибором для масиву:

```text
[7, 3, 5, 1]
```

**Прохід 1.** Найменше число в усьому масиві — `1`. Міняємо місцями `7` і `1`:

```text
[1, 3, 5, 7]
 ↑
Перша позиція вже правильна.
```

**Прохід 2.** У частині `[3, 5, 7]` найменшим є `3`. Перестановка не потрібна:

```text
[1, 3, 5, 7]
    ↑
Перші дві позиції правильні.
```

**Прохід 3.** У частині `[5, 7]` найменшим є `5`:

```text
[1, 3, 5, 7]
       ↑
```

**Кінцевий результат:**

```text
[1, 3, 5, 7]
```

Інваріант зберігався після кожного проходу: ліва частина була впорядкована й більше не змінювалася.

## 6. Кодовий приклад

Приклад сортує масив `[7, 3, 5, 1]`. Кожен метод змінює передану копію масиву, виводить проміжні стани та повертає кількість виконаних порівнянь.

### Файл `Source/Practical3.cs`

```csharp
namespace TheoryOfAlgorithms.Source;

public static class Practical3
{
    public static int SelectionSort(int[] values, bool showSteps = true)
    {
        int comparisons = 0;
        for (int i = 0; i < values.Length - 1; i++)
        {
            int minIndex = i; // Позиція найменшого знайденого елемента.
            for (int j = i + 1; j < values.Length; j++)
            {
                comparisons++;
                if (values[j] < values[minIndex])
                    minIndex = j;
            }
            int temp = values[i];
            values[i] = values[minIndex];
            values[minIndex] = temp;
            if (showSteps) PrintArray($"Прохід {i + 1}", values);
        }
        return comparisons;
    }

    public static int InsertionSort(int[] values, bool showSteps = true)
    {
        int comparisons = 0;
        for (int i = 1; i < values.Length; i++)
        {
            int current = values[i]; // Елемент, який потрібно вставити.
            int j = i - 1;
            while (j >= 0)
            {
                comparisons++;
                if (values[j] <= current) break;
                values[j + 1] = values[j];
                j--;
            }
            values[j + 1] = current;
            if (showSteps) PrintArray($"Вставка {i}", values);
        }
        return comparisons;
    }

    public static int ShellSort(int[] values, bool showSteps = true)
    {
        int comparisons = 0;
        for (int gap = values.Length / 2; gap > 0; gap /= 2)
        {
            for (int i = gap; i < values.Length; i++)
            {
                int current = values[i];
                int j = i;
                while (j >= gap)
                {
                    comparisons++;
                    if (values[j - gap] <= current) break;
                    values[j] = values[j - gap];
                    j -= gap;
                }
                values[j] = current;
            }
            if (showSteps) PrintArray($"Крок gap = {gap}", values);
        }
        return comparisons;
    }

    public static void Run()
    {
        int[] numbers = { 7, 3, 5, 1 }; // Дані індивідуального варіанта.
        int[] selection = (int[])numbers.Clone();
        int[] insertion = (int[])numbers.Clone();
        int[] shell = (int[])numbers.Clone();

        PrintArray("Початковий масив", numbers);
        int selectionCount = SelectionSort(selection);
        int insertionCount = InsertionSort(insertion);
        int shellCount = ShellSort(shell);

        PrintArray("Вибором", selection);
        PrintArray("Вставками", insertion);
        PrintArray("Шелла", shell);
        Console.WriteLine($"Порівняння: вибором — {selectionCount}, " +
                          $"вставками — {insertionCount}, Шелла — {shellCount}");
    }

    public static void PrintArray(string name, int[] values)
    {
        Console.WriteLine($"{name}: [{string.Join(", ", values)}]");
    }
}
```

### Файл `Program.cs`

```csharp
using TheoryOfAlgorithms.Source;

Practical3.Run();
```

Вхідні дані містяться в масиві `numbers` у методі `Run`. Для свого варіанта потрібно змінити лише числа цього масиву. Три виклики методів запускають алгоритми, а змінні `selectionCount`, `insertionCount` і `shellCount` зберігають кількість порівнянь.

Очікуваний основний результат:

```text
Початковий масив: [7, 3, 5, 1]
Вибором: [1, 3, 5, 7]
Вставками: [1, 3, 5, 7]
Шелла: [1, 3, 5, 7]
Порівняння: вибором — 6, вставками — 6, Шелла — 7
```

Перед підсумком програма також виведе проміжні стани. Для інших масивів кількість порівнянь може відрізнятися.

## 7. Перевірка коректності

Тестовий випадок містить конкретні вхідні дані та відомий очікуваний результат. Перевірка успішна, якщо фактичний масив повністю збігається з очікуваним.

| № | Вхідні дані | Що перевіряється | Очікуваний результат |
|---:|---|---|---|
| 1 | `[7, 3, 5, 1]` | Звичайний випадок | `[1, 3, 5, 7]` |
| 2 | `[5]` | Один елемент | `[5]` |
| 3 | `[]` | Порожній масив | `[]` |
| 4 | `[3, 3, 1]` | Однакові значення | `[1, 3, 3]` |
| 5 | `[1, 2, 3, 4]` | Уже впорядкований масив | `[1, 2, 3, 4]` |

### Файл `Tests/Practical3Tests.cs`

```csharp
using TheoryOfAlgorithms.Source;

namespace TheoryOfAlgorithms.Tests;

public static class Practical3Tests
{
    public static void RunTests()
    {
        int[] values = { 7, 3, 5, 1 };
        Practical3.SelectionSort(values, false);
        Check("Сортування вибором", values, new[] { 1, 3, 5, 7 });

        int[] oneValue = { 5 };
        Practical3.InsertionSort(oneValue, false);
        Check("Один елемент", oneValue, new[] { 5 });

        int[] repeated = { 3, 3, 1 };
        Practical3.ShellSort(repeated, false);
        Check("Однакові значення", repeated, new[] { 1, 3, 3 });
    }

    private static void Check(string name, int[] actual, int[] expected)
    {
        bool equal = actual.Length == expected.Length;
        for (int i = 0; i < actual.Length && equal; i++)
            if (actual[i] != expected[i]) equal = false;

        Console.WriteLine(equal ? $"Успішно: {name}" : $"Помилка: {name}");
    }
}
```

Для свого варіанта самостійно додайте 2–3 перевірки. Рекомендовано перевірити порожній масив, уже впорядковані числа та масив із повтореннями.

## 8. Теоретичний аналіз алгоритмів

| Алгоритм | Основна операція | Час у простому випадку | Час у складному випадку | Додаткова пам’ять |
|---|---|---|---|---|
| Вибором | порівняння з поточним мінімумом | `Θ(n²)` | `Θ(n²)` | `O(1)` |
| Вставками | порівняння з елементами ліворуч | `Θ(n)` | `Θ(n²)` | `O(1)` |
| Шелла | порівняння через поточний `gap` | залежить від кроків | до `O(n²)` для простих кроків | `O(1)` |

При збільшенні масиву кількість порівнянь зростає. Сортування вибором майже не реагує на початковий порядок. Вставки виконують значно менше роботи для вже впорядкованого масиву. Результат Шелла залежить від початкового порядку та послідовності `gap`.

6. самостійно розроблені тестові випадки;
7. відсортовані масиви та кількість порівнянь;
8. коротке пояснення результатів;
9. висновки.

У висновках 3–5 реченнями зазначте, які алгоритми розглянуто, які дані використано, який результат отримано, як перевірено правильність і який алгоритм виконав менше порівнянь.

## 12. Теоретичні питання для самостійного опрацювання

1. Для чого використовують сортування?
2. Як сортування вибором знаходить елемент для наступної позиції?
3. Як працює вставка елемента у впорядковану частину?
4. Для чого в сортуванні Шелла потрібна змінна `gap`?
5. Що називають інваріантом циклу?

## 14. Тестові завдання

1. Що виконує алгоритм сортування?
   - A. Упорядковує елементи
   - B. Видаляє всі елементи
   - C. Створює випадкові числа
   - D. Зчитує файл

2. Що шукає сортування вибором на кожному проході?
   - A. Суму елементів
   - B. Середнє значення
   - C. Найменший елемент невпорядкованої частини
   - D. Останній індекс

3. Який результат сортування `[4, 1, 3]` за зростанням?
   - A. `[4, 3, 1]`
   - B. `[1, 3, 4]`
   - C. `[3, 1, 4]`
   - D. `[1, 4, 3]`

4. Який інваріант має сортування вставками?
   - A. Права частина завжди порожня
   - B. Усі числа однакові
   - C. Масив не змінюється
   - D. Ліва оброблена частина впорядкована

5. Для чого потрібен `gap` у сортуванні Шелла?
   - A. Для порівняння елементів на певній відстані
   - B. Для зберігання суми
   - C. Для введення даних
   - D. Для видалення масиву

6. Яка складність сортування вибором?
   - A. `Θ(1)`
   - B. `Θ(log n)`
   - C. `Θ(n²)`
   - D. `Θ(n)`

7. Для якого масиву вставки зазвичай виконують найменше переміщень?
   - A. Випадкового
   - B. Уже впорядкованого
   - C. У зворотному порядку
   - D. Порожнього файла

8. Що має бути однаковим після трьох правильних сортувань одного масиву?
   - A. Кількість порівнянь
   - B. Кількість циклів
   - C. Проміжні стани
   - D. Кінцевий упорядкований масив

9. Який масив утвориться після першого проходу вибором для `[5, 3, 1]`?
   - A. `[1, 3, 5]`
   - B. `[3, 5, 1]`
   - C. `[5, 1, 3]`
   - D. `[3, 1, 5]`

10. Яка додаткова пам’ять потрібна наведеним алгоритмам?
    - A. `O(n²)`
    - B. `O(n)`
    - C. `O(1)`
    - D. `O(log n)`
