## 2. Теоретичні відомості

### 2.1. Потокова мережа

**Потокова мережа** — це орієнтований граф, у якому кожен канал має пропускну здатність.

- **джерело** `s` — вершина, з якої виходить потік;
- **стік** `t` — вершина, до якої надходить потік;
- `capacity[u, v]` — найбільша кількість одиниць, яку можна передати каналом `u → v`;
- `flow[u, v]` — фактичний потік через цей канал.

Наприклад, канал `0 → 1` із пропускною здатністю `3` може передати не більше трьох одиниць за один умовний проміжок часу.

### 2.2. Умови коректного потоку

Потік повинен виконувати дві основні умови.

**Обмеження пропускної здатності:**

```text
0 ≤ flow[u, v] ≤ capacity[u, v]
```

**Збереження потоку:** для кожної проміжної вершини кількість потоку, що надійшла, дорівнює кількості потоку, що вийшла.

Джерело створює потік, а стік його приймає.

### 2.3. Залишкова мережа

**Залишкова пропускна здатність** показує, скільки потоку ще можна передати каналом. Спочатку вона дорівнює початковій пропускній здатності.

Якщо шляхом передано `2` одиниці через канал місткістю `3`, то прямий залишок стає `1`. Також створюється зворотна можливість на `2` одиниці. Вона дозволяє алгоритму пізніше виправити раніше обраний маршрут.

```text
До передавання: residual[0,1] = 3
Передано: 2
Після: residual[0,1] = 1
       residual[1,0] = 2
```

### 2.4. Збільшувальний шлях

**Збільшувальний шлях** — шлях від джерела до стоку, усі ребра якого мають додатну залишкову пропускну здатність.

Додатковий потік шляху дорівнює найменшому залишку серед його ребер. Це ребро називають вузьким місцем.

```text
0 → 1: залишок 3
1 → 3: залишок 2
Додатковий потік шляху: min(3, 2) = 2
```

### 2.5. Алгоритм Едмондса—Карпа

Алгоритм повторює такі дії:

1. За допомогою BFS знаходить шлях від джерела до стоку в залишковій мережі.
2. Визначає найменшу залишкову пропускну здатність на шляху.
3. Зменшує прямі залишки та збільшує зворотні.
4. Додає знайдене значення до загального потоку.
5. Завершує роботу, коли BFS більше не знаходить шлях до стоку.

### 2.6. Мінімальний розріз

**Розріз** ділить вершини на дві групи:

- `S` містить джерело;
- `T` містить стік.

Пропускна здатність розрізу — сума початкових місткостей усіх ребер із `S` до `T`.

Після знаходження максимального потоку програма запускає обхід із джерела за ребрами з додатним залишком. Досяжні вершини утворюють `S`, решта — `T`. Ребра з `S` до `T` утворюють мінімальний розріз.

Теорема про максимальний потік і мінімальний розріз стверджує: значення максимального потоку дорівнює пропускній здатності мінімального розрізу.

### 2.7. Часова і просторова складність

Для алгоритму Едмондса—Карпа стандартна часова складність становить `O(V · E²)`, де `V` — кількість вершин, а `E` — кількість орієнтованих ребер. У цій роботі графи дуже малі, тому важливіше зрозуміти зміну залишкової мережі.

Матриці пропускних здатностей і залишків потребують `O(V²)` пам’яті. Масиви BFS потребують `O(V)` додаткової пам’яті.

| Позначення | Значення |
|---|---|
| `V` | кількість вершин мережі |
| `E` | кількість каналів |
| `O(V · E²)` | верхня оцінка часу Едмондса—Карпа |
| `O(V²)` | пам’ять для матриці залишків |

### 2.8. Обов’язковий наочний приклад

Нехай мережа має канали:

```text
0 → 1: 3
0 → 2: 2
1 → 2: 1
1 → 3: 2
2 → 3: 3
```

`0` — склад, `1` і `2` — проміжні пункти, `3` — магазин.

**Шлях 1:**

```text
0 → 1 → 3
min(3, 2) = 2
Загальний потік: 2
```

**Шлях 2:**

```text
0 → 2 → 3
min(2, 3) = 2
Загальний потік: 2 + 2 = 4
```

**Шлях 3:**

```text
0 → 1 → 2 → 3
min(1, 1, 1) = 1
Загальний потік: 4 + 1 = 5
```

Після цього обидва канали, що виходять із джерела, заповнені:

```text
0 → 1: 3 із 3
0 → 2: 2 із 2
```

Новий шлях від `0` до `3` відсутній.

**Максимальний потік:** `5`.

**Мінімальний розріз:**

```text
S = {0}
T = {1, 2, 3}
Ребра розрізу: 0→1 (3), 0→2 (2)
Пропускна здатність: 3 + 2 = 5
```

У прикладній інтерпретації магазин може отримувати не більше п’яти одиниць товару, а вузьким місцем є сумарна пропускна здатність каналів, що виходять зі складу.

## 6. Кодовий приклад

Нуль у матриці означає відсутність каналу. Метод `MaxFlow` створює копію матриці для залишкових пропускних здатностей. BFS заповнює масив `parent`, за яким відновлюється знайдений шлях.

### Файл `Source/Practical9.cs`

```csharp
namespace TheoryOfAlgorithms.Source;

public static class Practical9
{
    public static int MaxFlow(int[,] capacity, int source, int sink,
                              out int[,] residual, bool showPaths)
    {
        int n = capacity.GetLength(0);
        residual = (int[,])capacity.Clone();
        int[] parent = new int[n];
        int maxFlow = 0;

        while (Bfs(residual, source, sink, parent))
        {
            int pathFlow = int.MaxValue;

            // Рухаємося від стоку до джерела і знаходимо вузьке місце.
            for (int v = sink; v != source; v = parent[v])
            {
                int u = parent[v];
                pathFlow = Math.Min(pathFlow, residual[u, v]);
            }

            if (showPaths) PrintPath(parent, source, sink, pathFlow);

            // Оновлюємо прямі й зворотні залишкові пропускні здатності.
            for (int v = sink; v != source; v = parent[v])
            {
                int u = parent[v];
                residual[u, v] -= pathFlow;
                residual[v, u] += pathFlow;
            }
            maxFlow += pathFlow;
        }
        return maxFlow;
    }

    private static bool Bfs(int[,] residual, int source, int sink,
                            int[] parent)
    {
        int n = residual.GetLength(0);
        bool[] visited = new bool[n];
        int[] queue = new int[n];
        int start = 0;
        int end = 0;

        queue[end++] = source;
        visited[source] = true;
        parent[source] = -1;

        while (start < end)
        {
            int u = queue[start++];
            for (int v = 0; v < n; v++)
            {
                if (!visited[v] && residual[u, v] > 0)
                {
                    visited[v] = true;
                    parent[v] = u;
                    queue[end++] = v;
                }
            }
        }
        return visited[sink];
    }

    private static void PrintPath(int[] parent, int source, int sink,
                                  int pathFlow)
    {
        int[] reverse = new int[parent.Length];
        int length = 0;
        for (int v = sink; v != -1; v = parent[v])
        {
            reverse[length++] = v;
            if (v == source) break;
        }

        Console.Write("Шлях: ");
        for (int i = length - 1; i >= 0; i--)
        {
            Console.Write(reverse[i]);
            if (i > 0) Console.Write(" → ");
        }
        Console.WriteLine($", додатковий потік: {pathFlow}");
    }

    public static bool[] FindReachable(int[,] residual, int source)
    {
        int n = residual.GetLength(0);
        bool[] reachable = new bool[n];
        int[] queue = new int[n];
        int start = 0;
        int end = 0;
        queue[end++] = source;
        reachable[source] = true;

        while (start < end)
        {
            int u = queue[start++];
            for (int v = 0; v < n; v++)
                if (!reachable[v] && residual[u, v] > 0)
                {
                    reachable[v] = true;
                    queue[end++] = v;
                }
        }
        return reachable;
    }

    public static int PrintMinCut(int[,] capacity, bool[] reachable)
    {
        int cutCapacity = 0;
        Console.WriteLine("Ребра мінімального розрізу:");
        for (int u = 0; u < capacity.GetLength(0); u++)
            for (int v = 0; v < capacity.GetLength(1); v++)
                if (reachable[u] && !reachable[v] && capacity[u, v] > 0)
                {
                    Console.WriteLine($"{u} → {v}: {capacity[u, v]}");
                    cutCapacity += capacity[u, v];
                }
        return cutCapacity;
    }

    public static void Run()
    {
        int[,] capacity =
        {
            { 0, 3, 2, 0 },
            { 0, 0, 1, 2 },
            { 0, 0, 0, 3 },
            { 0, 0, 0, 0 }
        }; // Матриця пропускних здатностей варіанта.

        int maxFlow = MaxFlow(capacity, 0, 3, out int[,] residual, true);
        Console.WriteLine($"Максимальний потік: {maxFlow}");

        bool[] reachable = FindReachable(residual, 0);
        int cutCapacity = PrintMinCut(capacity, reachable);
        Console.WriteLine($"Пропускна здатність розрізу: {cutCapacity}");
    }
}
```

## 8. Теоретичний аналіз алгоритму

Основною операцією є перегляд залишкових каналів під час BFS. Кількість повторних запусків BFS залежить від структури мережі та пропускних здатностей.

| Частина | Часова складність | Додаткова пам’ять |
|---|---|---|
| Один BFS у матриці | `O(V²)` | `O(V)` |
| Едмондс—Карп | стандартна оцінка `O(V · E²)` | `O(V²)` |
| Пошук сторони `S` розрізу | `O(V²)` для матриці | `O(V)` |
