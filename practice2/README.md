## 2. Теоретичні відомості

### 2.1. Абстрактний тип даних

**Абстрактний тип даних** визначає, які операції можна виконувати з даними, але не вимагає одного конкретного способу їх зберігання. Наприклад, стек можна реалізувати за допомогою масиву або зв’язного списку. Для користувача структури важливо, що до стека можна додати елемент, вилучити верхній елемент і переглянути його.

У цій роботі розглядаються дві прості реалізації:

- стек цілих чисел на основі масиву;
- черга цілих чисел на основі однозв’язного списку.

### 2.2. Стек

**Стек** працює за правилом **LIFO** — *Last In, First Out*: останній доданий елемент вилучається першим. Побутовий приклад — стопка тарілок.

Основні операції стека:

- `Push(value)` — додати елемент на вершину;
- `Pop()` — вилучити і повернути верхній елемент;
- `Peek()` — переглянути верхній елемент без вилучення;
- `IsEmpty()` — перевірити, чи порожній стек.

У стеку на основі масиву змінна `top` зберігає індекс верхнього елемента. Значення `-1` означає, що стек порожній.

```text
Масив: [10, 20, 30, _, _]
Індекс:  0   1   2  3  4
top = 2
```

### 2.3. Черга

**Черга** працює за правилом **FIFO** — *First In, First Out*: перший доданий елемент вилучається першим. Побутовий приклад — черга людей до каси.

Основні операції черги:

- `Enqueue(value)` — додати елемент у кінець;
- `Dequeue()` — вилучити і повернути перший елемент;
- `Peek()` — переглянути перший елемент без вилучення;
- `IsEmpty()` — перевірити, чи порожня черга.

В однозв’язному списку кожен вузол зберігає значення та посилання `Next` на наступний вузол. Посилання `front` указує на початок черги, а `rear` — на її кінець.

```text
front                         rear
  ↓                             ↓
[10 | •] → [20 | •] → [30 | null]
```

### 2.4. Часова і просторова складність

Позначення `O(...)` показує верхню оцінку зростання кількості операцій. `Ω(...)` показує нижню оцінку, а `Θ(...)` — однакову швидкість зростання і зверху, і знизу.

| Складність | Приблизна кількість операцій для `n = 10` | Просте пояснення |
|---|---:|---|
| `O(1)` | 1 | Кількість дій майже не залежить від розміру даних |
| `O(log n)` | 3–4 | На кожному кроці обсяг роботи суттєво зменшується |
| `O(n)` | 10 | Потрібно переглянути всі елементи |
| `O(n²)` | 100 | Для кожного елемента повторно переглядаються інші елементи |

Операції `Push`, `Pop`, `Enqueue` і `Dequeue` у наведених реалізаціях мають складність `Θ(1)`, бо виконують сталу кількість дій. Якщо послідовно додати `n` елементів, загальна кількість операцій матиме порядок `Θ(n)`. Обидві структури використовують `O(n)` пам’яті для зберігання `n` елементів.

### 2.5. Обов’язковий наочний приклад

Нехай початкова послідовність має вигляд:

```text
[4, 7, 2]
```

**Додавання чисел до стека:**

```text
Початковий стек:     []
Після Push(4):       [4]
Після Push(7):       [4, 7]       ← вершина 7
Після Push(2):       [4, 7, 2]    ← вершина 2
```

**Послідовне вилучення зі стека:**

```text
Pop() → 2, стек [4, 7]
Pop() → 7, стек [4]
Pop() → 4, стек []
Результат: [2, 7, 4]
```

Стек змінив порядок чисел на зворотний, тому що останнє додане число було вилучене першим.

**Додавання чисел до черги:**

```text
Початкова черга:     []
Після Enqueue(4):    [4]
Після Enqueue(7):    [4, 7]
Після Enqueue(2):    [4, 7, 2]
```

**Послідовне вилучення з черги:**

```text
Dequeue() → 4, черга [7, 2]
Dequeue() → 7, черга [2]
Dequeue() → 2, черга []
Результат: [4, 7, 2]
```

Черга зберегла початковий порядок, тому що перше додане число було вилучене першим.

## 6. Кодовий приклад

Приклад додає три числа до стека і черги, показує стан структур після кожного кроку, а потім вилучає елементи. Для спрощення обидві структури працюють тільки з цілими числами.

### Файл `Source/Practical2.cs`

```csharp
namespace TheoryOfAlgorithms.Source;

public static class Practical2
{
    // Один вузол черги: число та посилання на наступний вузол.
    private class Node
    {
        public int Value;
        public Node? Next;

        public Node(int value)
        {
            Value = value;
            Next = null;
        }
    }

    // Додає число у стек. top указує на поточну вершину.
    public static void Push(int[] stack, ref int top, int value)
    {
        top++;
        stack[top] = value;
    }

    // Повертає верхнє число та зменшує індекс вершини.
    public static int Pop(int[] stack, ref int top)
    {
        int value = stack[top];
        top--;
        return value;
    }

    // Запускає приклад із конкретними числами.
    public static void Run()
    {
        int[] numbers = { 4, 7, 2 }; // Дані, які змінюються за варіантом.
        int[] stack = new int[numbers.Length];
        int top = -1; // Значення -1 означає, що стек порожній.

        Console.WriteLine("Робота стека:");
        foreach (int number in numbers)
        {
            Push(stack, ref top, number);
            Console.WriteLine($"Push({number}), вершина: {stack[top]}");
        }

        Console.Write("Результат Pop: ");
        while (top >= 0)
            Console.Write($"{Pop(stack, ref top)} ");

        Node? front = null; // Перший вузол черги.
        Node? rear = null;  // Останній вузол черги.

        Console.WriteLine("\nРобота черги:");
        foreach (int number in numbers)
        {
            Node newNode = new Node(number);
            if (rear == null)
                front = rear = newNode; // Додаємо перший вузол.
            else
            {
                rear.Next = newNode;    // Старий кінець веде до нового вузла.
                rear = newNode;         // Новий вузол стає кінцем черги.
            }
            Console.WriteLine($"Enqueue({number}), початок: {front!.Value}");
        }

        Console.Write("Результат Dequeue: ");
        while (front != null)
        {
            Console.Write($"{front.Value} ");
            front = front.Next; // Наступний вузол стає початком черги.
        }
        rear = null; // Після вилучення всіх вузлів черга порожня.
    }
}
```

### Файл `Program.cs`

```csharp
using TheoryOfAlgorithms.Source;

Practical2.Run();
```

Вхідні дані містяться в масиві `numbers` на початку методу `Run`. Для свого варіанта потрібно змінити саме числа цього масиву. Методи `Push` і `Pop` працюють зі стеком. Додавання до черги виконується в другому циклі `foreach`, а вилучення — у циклі `while`.

Очікуване виведення:

```text
Робота стека:
Push(4), вершина: 4
Push(7), вершина: 7
Push(2), вершина: 2
Результат Pop: 2 7 4
Робота черги:
Enqueue(4), початок: 4
Enqueue(7), початок: 4
Enqueue(2), початок: 4
Результат Dequeue: 4 7 2
```

Стек повернув числа у зворотному порядку, а черга — у початковому.

## 7. Перевірка коректності

Тестовий випадок — це конкретні вхідні дані та відомий очікуваний результат. Якщо фактичний результат збігається з очікуваним, перевірка успішна.

| № | Вхідні дані | Що перевіряється | Очікуваний результат |
|---:|---|---|---|
| 1 | `[4, 7, 2]` | Звичайна послідовність | стек: `[2, 7, 4]`, черга: `[4, 7, 2]` |
| 2 | `[5]` | Один елемент | обидві структури повертають `[5]` |
| 3 | `[]` | Порожня послідовність | жоден елемент не вилучається |
| 4 | `[3, 3]` | Однакові значення | обидві структури повертають два числа `3` |
| 5 | `[1, 2, 3, 4]` | Уже впорядковані дані | стек повертає `[4, 3, 2, 1]` |

### Файл `Tests/Practical2Tests.cs`

```csharp
using TheoryOfAlgorithms.Source;

namespace TheoryOfAlgorithms.Tests;

public static class Practical2Tests
{
    public static void RunTests()
    {
        // Перевіряємо, що стек повертає останній доданий елемент.
        int[] stack = new int[3];
        int top = -1;
        Practical2.Push(stack, ref top, 4);
        Practical2.Push(stack, ref top, 7);
        Practical2.Push(stack, ref top, 2);
        Check("Першим зі стека виходить 2",
            Practical2.Pop(stack, ref top), 2);

        // Після одного Pop новою вершиною має бути число 7.
        Check("Другим зі стека виходить 7",
            Practical2.Pop(stack, ref top), 7);

        // Стек з одного елемента повинен повернути цей елемент.
        int[] oneValueStack = new int[1];
        int oneValueTop = -1;
        Practical2.Push(oneValueStack, ref oneValueTop, 5);
        Check("Стек з одного елемента",
            Practical2.Pop(oneValueStack, ref oneValueTop), 5);
    }

    // Порівнює фактичне число з очікуваним і показує результат.
    private static void Check(string name, int actual, int expected)
    {
        if (actual == expected)
            Console.WriteLine($"Успішно: {name}");
        else
            Console.WriteLine($"Помилка: {name}. Очікувалося {expected}, отримано {actual}");
    }
}
```

## 8. Теоретичний аналіз алгоритмів

### Стек на основі масиву

Основною операцією є зміна `top` і звернення до одного елемента масиву. `Push` та `Pop` виконуються за `Θ(1)`. Для зберігання `n` чисел потрібен масив із `n` позицій, тому просторова складність становить `O(n)`. Обробка всіх `n` чисел потребує `Θ(n)` часу.

### Черга на основі зв’язного списку

Основною операцією є зміна одного або двох посилань між вузлами. `Enqueue` і `Dequeue` виконуються за `Θ(1)`, оскільки програма має прямі посилання на початок і кінець. Для `n` вузлів потрібна `O(n)` пам’ять.

**Фрагмент очікуваного результату:** стек починається з `412`; черга — з `201`.

**Додаткова невелика зміна:** додайте аудиторію `215` наприкінці.

**Підказка для тестів:** перевірте один номер та порядок перших двох номерів.

### Варіант 9. Коди міст

**Вхідні дані:** `[11, 22, 33, 44, 55]`.

**Фрагмент очікуваного результату:** стек — `55 44 33 22 11`; черга — `11 22 33 44 55`.

**Додаткова невелика зміна:** замініть останній код на `66`.

**Підказка для тестів:** перевірте перше та останнє вилучення.

### Варіант 10. Бали команд

**Додаткова невелика зміна:** додайте ще одне число `10`.

**Підказка для тестів:** перевірте збереження двох однакових значень і один елемент.

### Варіант 11. Номери файлів

### Варіант 12. Запити користувачів
